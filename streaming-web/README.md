# FLOWTV Streaming

Catálogo web responsivo para descobrir e reproduzir curtas e filmes de acesso aberto.

## Incluído

- Busca e navegação por catálogo
- Player HTML5 com retomada de reprodução
- Minha lista e progresso salvos no navegador
- Conteúdo de demonstração com créditos e links para fontes/licenças
- Visual responsivo para computador e celular

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Os vídeos e cartazes de demonstração são carregados de URLs públicas do Google. O app não armazena nem redistribui os arquivos de vídeo. As obras abertas exibem seus créditos e links de origem.
